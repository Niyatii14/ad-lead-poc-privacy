# Privacy Policy — AD Lead POC Demo

**Last updated:** October 14, 2026

## 1. About This Project

AD Lead POC Demo is a demonstration project created to test the integration of Meta Lead Ads with a React Native application.

## 2. Information We Collect

When a test lead is submitted, the application may receive contact information such as a person's name and email address through Meta's lead-generation tools.

## 3. How We Use Information

Information is used only to test, demonstrate, and troubleshoot the lead submission and retrieval workflow.

## 4. Data Storage and Retention

Lead information may be processed by the project's backend and stored temporarily for testing. Test data will be deleted when it is no longer needed for the demonstration.

## 5. Sharing of Information

This demonstration does not intentionally sell personal information. Data may be processed by Meta and the hosting or infrastructure providers used by the project as necessary to operate the integration.

## 6. Data Security

Reasonable measures will be taken to protect test data. However, no system can guarantee absolute security.
